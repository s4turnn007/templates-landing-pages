Portfólio de Templates de Landing Pages

https://s4turnn007.github.io/templates-landing-pages/

Este repositório contém um portfólio de templates de landing pages, desenvolvido para demonstrar habilidades em HTML5, CSS3 e design responsivo. O projeto reúne modelos prontos para diferentes nichos de mercado, com foco em organização, simplicidade e estética moderna.

Estrutura do Projeto

O projeto está organizado da seguinte forma:

index.html – Página principal do portfólio, que exibe todos os templates em forma de cards.
/images/ – Pasta com imagens utilizadas nos templates e na página principal.
/template1, /template2, /template3, /template4/ – Pastas contendo os arquivos de cada template individual, incluindo index.html e recursos específicos.

Funcionalidade

Cada card do portfólio abre o template correspondente em uma nova aba, permitindo visualizar a landing page completa. Todos os templates são responsivos e podem ser facilmente adaptados ou personalizados para diferentes projetos e necessidades.

Tecnologias Utilizadas

HTML
CSS
JavaScript
Grid e Flexbox para layout responsivo
Google Fonts (Montserrat)

Objetivo

O projeto tem como objetivo demonstrar habilidades de desenvolvimento front-end e design de interfaces, criando templates modernos, funcionais e de fácil adaptação para diversos nichos de mercado.

//*

This repository contains a portfolio of landing page templates, designed to demonstrate HTML5, CSS3, and responsive design skills. The project brings together ready-made templates for different market niches, with a focus on organization, simplicity, and a modern aesthetic.

Project Structure

The project is organized as follows:

index.html – Main portfolio page, which displays all templates in card format.
/images/ – Folder with images used in the templates and on the main page.
/template1, /template2, /template3, /template4/ – Folders containing the files for each individual template, including index.html and specific resources.

Functionality

Each portfolio card opens the corresponding template in a new tab, allowing you to view the complete landing page. All templates are responsive and can be easily adapted or customized for different projects and needs.

Technologies Used

HTML
CSS
JavaScript
Grid and Flexbox for responsive layout
Google Fonts (Montserrat)

Objective

The project aims to demonstrate front-end development and interface design skills, creating modern, functional, and easily adaptable templates for various market niches.
